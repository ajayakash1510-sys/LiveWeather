🍽️ What is an API in simple words?

Think of an API (Application Programming Interface) like a waiter in a restaurant:

  • You (the Client / Browser): Look at the menu and place an order ("Give me Chennai's weather!").
  • The Waiter (The API): Takes your request to the kitchen and brings back your order.
  • The Kitchen (The Weather Server): Prepares the requested data and packages it as JSON text.

Without an API, your website wouldn't know the temperature in Chennai because it has no weather sensors of its own!

🔄 How a Weather Website Gets Live Data

  1. User enters a city: e.g., "Chennai".
  2. Step 1 - Geocoding: The app calls Open-Meteo's Geocoding API to find Chennai's latitude (13.0827) and longitude (80.2707).
  3. Step 2 - Forecast Fetch: The app requests current weather and daily forecast from Open-Meteo using those coordinates.
  4. Step 3 - Display: JavaScript parses the JSON response and updates the HTML text, emojis, and forecast cards.

🌐 Example URL for Chennai Current Weather

Copy or click this URL in a new tab to see raw weather data straight from the satellite & weather models:

https://api.open-meteo.com/v1/forecast?latitude=13.0827&longitude=80.2707&current=temperature_2m,relative_humidity_2m,weather_code,wind_speed_10m&daily=weather_code,temperature_2m_max,temperature_2m_min&timezone=auto&forecast_days=3

📦 What the JSON Response Means (Field-by-Field)

"latitude": 13.08 The precise geographical latitude coordinate used for the calculation.
"longitude": 80.28 The geographical longitude coordinate of the location.
"temperature_2m": 31.4 Air temperature measured at 2 meters above ground level (standard meteorological height) in °C.
"relative_humidity_2m": 72 Relative humidity percentage at 2 meters above ground.
"weather_code": 1 WMO standard weather code (e.g., 0 = Clear Sky ☀️, 1-3 = Partly Cloudy ⛅, 61 = Rain 🌧️, 95 = Thunderstorm ⛈️).
"wind_speed_10m": 12.5 Wind speed measured at 10 meters above ground level (km/h).
"daily": { ... } Arrays of daily timestamps, WMO weather codes, max temperatures, and min temperatures for the 3-day forecast.
